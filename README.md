# Blood Donor Management System — Frontend

## About the Project
The Blood Donor Management System is a web-based application designed to help manage blood donor information. This repository contains the frontend interface of the project.

## Features
- User login page
- Donor dashboard
- User-friendly interface for managing donor information
- Frontend integration with a Spring Boot backend

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Files
- `login.html` — Login page
- `index.html` — Donor dashboard

## How to Run
1. Clone or download this repository.
2. Open `login.html` in your web browser.
3. For full functionality, run the corresponding Spring Boot backend and configure the frontend to connect to it.

## Backend
The backend is maintained in a separate repository.
